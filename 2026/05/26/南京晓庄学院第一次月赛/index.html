P14584 [LNCPC 2025] 点击平衡球

题目背景

Z 形管道猫推荐您来玩平衡球（Ballance）。在游戏中，玩家要操纵一个可以改变自身材质（即物理性质）的球在由路面和机关构成的庞大而复杂的迷宫建筑中穿梭，避开陷阱、运用机关并破解一个个谜题，最终到达终点。

题目描述

平衡球有 333 种材质（纸球、木球、石球）。在游戏中，平衡球需要通过 nnn 个机关，每个机关各自只允许特定一些材质的平衡球通过。初始，您需要花费 111 单位的代价将平衡球选定为一种材质。在通过每个机关前，您可以花费 111 单位的代价将平衡球切换为另一种材质，也可以不花费代价保持当前材质。

现在您可以任意安排机关的通过顺序，请您求出平衡球通过这 nnn 个机关所需的最小代价。

输入格式

第一行给定一个整数 n(1≤n≤100)n(1\le n\le 100)n(1≤n≤100)，表示机关总数。

接下来 nnn 行，每行给定三个整数 ai,1,ai,2,ai,3(ai,1,ai,2,ai,3∈{0,1})a_{i,1},a_{i,2},a_{i,3}(a_{i,1},a_{i,2},a_{i,3}\in\{0,1\})ai,1​,ai,2​,ai,3​(ai,1​,ai,2​,ai,3​∈{0,1})，其中第 iii 行的第 jjj 个整数 ai,ja_{i,j}ai,j​ 为 000、111 分别表示给定的第 iii 个机关不允许、允许第 jjj 种材质的平衡球通过。保证 ai,1,ai,2,ai,3a_{i,1},a_{i,2},a_{i,3}ai,1​,ai,2​,ai,3​ 不全为 000。

输出格式

一个整数，表示经由合理安排机关的通过顺序和材质的代价花费，平衡球通过这 nnn 个机关所需的最小代价。

输入输出样例 #1

输入 #1

输出 #1

说明/提示

一种机关的通过顺序和材质的代价花费的合理安排如下：
机关的通过顺序依次为给定的第 333、111、444、555、222 个机关。
初始，花费 111 单位的代价将平衡球选定为第 222 种材质。
在通过给定的第 333 个机关前，不花费代价保持当前材质。
在通过给定的第 111 个机关前，花费 111 单位的代价将平衡球切换为第 111 种材质。
在通过给定的第 444 个机关前，花费 111 单位的代价将平衡球切换为第 333 种材质。
在通过给定的第 555 个机关前，不花费代价保持当前材质。
在通过给定的第 222 个机关前，不花费代价保持当前材质。

可以证明，经由合理安排机关的通过顺序和材质的代价花费，平衡球通过这 nnn 个机关所需的最小代价是 333。

题解：

发现结果一共只有三种。

  • 如果存在某一个位置，n 个点都可以经过，那么答案是 1。
  • 如果存在某三个机关，分别只能允许 1,2,3 经过，那么必须交换三次，答案是 3。
  • 否则答案是 2。

P14589 [LNCPC 2025] 子鼠

题目背景

Z 形管道猫正在研究如何高效发动《三国杀》中的“子鼠”。

题目描述

子鼠：技能，您可以选择一名卡牌数大于您的其他角色，然后获得其的一张卡牌。

总共有 nnn 名角色，您是第 111 名角色。初始，第 iii 名角色有 aia_iai​ 张卡牌。

请您求出只通过您发动任意次（可以零次）“子鼠”后，您的卡牌数的最大值。

输入格式

每个测试点包含多组测试数据。第一行给定一个整数 T(1≤T≤104)T(1\le T\le 10^4)T(1≤T≤104)，表示测试数据组数。

对于每组测试数据：
第一行给定一个整数 n(1≤n≤106)n(1\le n\le10^6)n(1≤n≤106)，表示角色数。
第二行给定 nnn 个整数 ai(0≤ai≤109)a_i(0\le a_i\le10^9)ai​(0≤ai​≤109)，其中第 iii 个整数 aia_iai​ 表示初始第 iii 名角色的卡牌数。

保证在每个测试点中所有测试数据的 nnn 的总和不超过 10610^6106。

输出格式

对于每组测试数据，输出一行一个整数，表示只通过您发动任意次“子鼠”后，您的卡牌数的最大值。

输入输出样例 #1

输入 #1

输出 #1

说明/提示

对于样例的第一组测试数据：
您发动第一次“子鼠”：选择第 222 名角色，然后获得其的一张卡牌。各角色的卡牌数变为 1,2,1\textbf{\color{red}1},\textbf{\color{red}2},11,2,1。
您发动第二次“子鼠”：选择第 222 名角色，然后获得其的一张卡牌。各角色的卡牌数变为 2,1,1\textbf{\color{red}2},\textbf{\color{red}1},12,1,1。
因为此时没有卡牌数大于您的其他角色，所以您无法发动第三次“子鼠”。
可以证明，只通过您发动任意次“子鼠”后，您的卡牌数的最大值是 222。

对于样例的第二组测试数据：
您发动第一次“子鼠”：选择第 333 名角色，然后获得其的一张卡牌。各角色的卡牌数变为 1,2,2,0\textbf{\color{red}1},2,\textbf{\color{red}2},01,2,2,0。
您发动第二次“子鼠”：选择第 222 名角色，然后获得其的一张卡牌。各角色的卡牌数变为 2,1,2,0\textbf{\color{red}2},\textbf{\color{red}1},2,02,1,2,0。
因为此时没有卡牌数大于您的其他角色，所以您无法发动第三次“子鼠”。
可以证明，只通过您发动任意次“子鼠”后，您的卡牌数的最大值是 222。

题解：

看完题目，可以发现如果想要你的手牌最大，那你肯定先从手牌小的人的手牌开始拿。

因为当你获得一张手牌时，必定有一个人失去一张手牌，所以这道题需要排序。

然后去找第一个比自己大的，然后去发动子鼠，可以发现的是，如果你找的是第 i 个人，他有aia_iai​的手牌，那么你的手牌数极限情况下应该是 (a1+ai+1)/2(a_1+a_i+1)/2(a1​+ai​+1)/2，注意这里不可以慢慢的自己加，别人减，回超时。
