B

如果 M = 0（也就是数组里没有 0）：无论怎么重排，任意非空前缀/后缀都不含 0，所以它们的 MEX 都是 0，必然会出现相等 ⇒ NO

如果 M = 1（有 0，但没有 1）：

  • 任意一段的 MEX 只可能是 0（没 0） 或 1（有 0）
  • 要让每个切分点前后 MEX 都不同，必须保证每个切分点两边不可能“同时有 0”
  • 这只有在 0 的出现次数恰好为 1 时成立（0 只在一边） ⇒ cnt0==1 YES，否则 NO

如果 M ≥ 2：一定能 YES

  • 构造：把所有 0 放到最前面，其余随便放后面
  • 设 c = cnt0
    • 当切分点 i < c：前缀只有 0（没有 1），所以 mex(prefix)=1；后缀含 0 且含所有 1..M-1，所以 mex(suffix)=M，不同
    • 当切分点 i ≥ c：后缀没有 0，所以 mex(suffix)=0；前缀至少有 0，因此 mex(prefix)≥1，不同
  • 所以对所有切分点都满足 ⇒ YES

D

1. 核心逻辑：什么是“更优 (Better)”？

根据题目定义，字符串 ttt 比 sss 更优，意味着存在一个位置 iii，使得：

  • ttt 和 sss 在 iii 之前的所有字符都相同。
  • 但是在位置 iii：s[i]=’)’s[i] = \text{')'}s[i]=’)’，而 t[i]=’(’t[i] = \text{'('}t[i]=’(’。
    • 注：在字典序中 ( 小于 )，所以此时 ttt 的字典序更小。

结论：我们要做的就是枚举这个位置 iii，试图把原字符串 sss 中某个位置的 ) 变成 (。

2. 如何把位置 iii 的 ) 变成 (？

假设我们在 sss 的下标 iii 处遇到了一个 )。为了让子序列 ttt 在这里变成 (，我们需要从 sss 的后面“借”一个 ( 过来。

  • 贪心策略：为了删掉的字符最少（即保留的长度最长），我们应该找离 iii 最近的下一个 (。
  • 假设这个最近的 ( 在位置 jjj（代码中记为 nx[i]）。
  • 代价：因为 jjj 是 iii 之后第一个出现的 (，说明 iii 和 jjj 之间（包括 iii 本身，但不包括 jjj）全都是 )。
    • 要把 jjj 处的 ( 挪到 iii 的位置用，意味着我们要删除下标从 iii 到 j−1j-1j−1 的所有字符（这些全是 )）。
    • 删除的右括号数量 = j−ij - ij−i。

3. 维持 RBS 的平衡 (Balance)

仅仅把 ) 删掉换成 ( 是不够的，因为这会破坏括号序列的平衡。

  • 原状态：sss 是平衡的（左括号总数 = 右括号总数）。
  • 操作后：我们在 i…j−1i \dots j-1i…j−1 这个区间删除了 k=j−ik = j - ik=j−i 个右括号 )。
  • 后果：现在的序列中，右括号少了 kkk 个，或者说左括号相对多出了 kkk 个。序列不再平衡，无法闭合。
  • 补救措施：为了让总平衡归零，我们必须在后面（即位置 jjj 之后）再删除 kkk 个左括号 (。

判定条件：只要 jjj 后面剩下的左括号数量足够多（≥k\ge k≥k 个），这个方案就是合法的。

注：只要总数量够扣，删掉左括号是不会导致中间过程出现“右括号比左括号多”的非法情况的（因为删除左括号只会让前缀和变小，而我们是在后缀删，不会影响前面的合法性）。

4. 计算公式

如果我们选定位置 iii 进行操作，且最近的左括号在 jjj：

  • 删除的 ) 数量 = j−ij - ij−i
  • 必须删除的 ( 数量 = j−ij - ij−i
  • 总共删除的字符数 = 2×(j−i)2 \times (j - i)2×(j−i)
  • 最终子序列长度 = n−2×(j−i)n - 2 \times (j - i)n−2×(j−i)

代码逻辑实现

为了实现上述逻辑，代码分为“预处理”和“枚举计算”两部分。

A. 预处理 (Preprocessing)

为了让检查过程在 O(1)O(1)O(1) 时间内完成，代码构建了两个辅助数组：

  1. nx 数组 (Next Open Bracket):
    • nx[i] 表示从下标 iii 开始（包含 iii），右边第一个 ( 的位置。
    • 如果 s[i]s[i]s[i] 本身是 (，则 nx[i] = i。
    • 如果 s[i]s[i]s[i] 是 )，则 nx[i] = nx[i+1]（继承后面的结果）。
    • 目的：快速找到上文提到的 jjj。
  2. suf 数组 (Suffix Sum of Open Brackets):
    • suf[i] 表示从下标 iii 到字符串末尾，一共有多少个 (。
    • 目的：快速判断 jjj 后面是否有足够的 ( 供我们删除以维持平衡。
